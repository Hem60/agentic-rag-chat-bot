# Corpus attribution

The `.txt` files here are plain-text extracts of English Wikipedia articles, fetched by
`python -m src.fetch_corpus`. Text is available under the Creative Commons
Attribution-ShareAlike 4.0 license (https://creativecommons.org/licenses/by-sa/4.0/).
Each file starts with the article title and URL; authors are listed in the article
history on Wikipedia. Changes made: references / external-links sections removed and
markup flattened to plain text.
